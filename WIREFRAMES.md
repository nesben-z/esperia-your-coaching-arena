## 📊 Légende

- `[ ]` = Bouton ou élément cliquable
- `┌─┐` = Conteneur/Card
- `│` = Séparateur vertical
- `─` = Séparateur horizontal
- `...` = Texte tronqué
- `📊 📈 ⏰ ⚡ ✓` = Icônes
- `▼` = Dropdown/Select
- `( )` = Radio button
- `[ ]` = Checkbox (si applicable)
